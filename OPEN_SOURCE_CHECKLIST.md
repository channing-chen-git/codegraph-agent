# Open Source Checklist

- [x] README describes purpose, architecture, usage and limitations.
- [x] No private repositories, secrets or real proprietary code are included.
- [x] Example repository is synthetic.
- [x] `.gitignore` excludes local traces, caches, environments and model files.
- [x] Offline evaluation does not require external APIs.
- [x] CI runs compile checks, unit tests and offline evaluation.
- [x] `environment.yml` and Dockerfile are provided for isolated runtime setup.
